## 0. ถ้ายังไม่มีไฟล์หรือภาพแนบมา
ส่งเช็กลิสต์นี้ให้เจ้าของช่อง แล้วรอ (ชื่อเมนูในแอปอาจต่างเล็กน้อยตามเวอร์ชัน):

**ทางที่ 1 (ดีที่สุด) — ดาวน์โหลดไฟล์จากคอม**
tiktok.com → ล็อกอิน → รูปโปรไฟล์ → **TikTok Studio** → **Analytics (การวิเคราะห์)** → เลือกช่วง 7 หรือ 28 วัน → ปุ่ม **ดาวน์โหลดข้อมูล / Export** → แนบไฟล์ที่ได้ (CSV/XLSX) มาในแชท
(ปุ่มดาวน์โหลดมีเฉพาะบนเว็บในคอม ไม่มีในแอปมือถือ)

**ทางที่ 2 — แคปจากแอปมือถือ** (โปรไฟล์ → ☰ → TikTok Studio → การวิเคราะห์)
1. แท็บ **ภาพรวม** ช่วง 7 วัน (ยอดวิว, ยอดดูโปรไฟล์, ไลก์, คอมเมนต์, แชร์, ผู้ติดตามสุทธิ)
2. แท็บ **เนื้อหา** — รายการคลิปพร้อมยอดวิว
3. คลิปที่โพสต์ช่วงนี้ **ทีละคลิป** (กดเข้าคลิป → การวิเคราะห์): เวลาดูเฉลี่ย, % ดูจบ, ผู้ติดตามใหม่, **กราฟการดูต่อ (retention)**, **แหล่งที่มาของยอดวิว** (For You / โปรไฟล์ / ค้นหา), คำค้นหา
4. แท็บ **ผู้ติดตาม** — ช่วงเวลา/วันที่ผู้ติดตามออนไลน์ (ใช้ปรับเวลาโพสต์)

## 1. เก็บและถอดข้อมูล
- สัปดาห์ของข้อมูล: `date +%G-W%V` (หรือสัปดาห์ที่ไฟล์ครอบคลุม)
- ไฟล์ CSV/XLSX: คัดลอกไปที่ `office/stats/raw/<วันที่>/` แล้วเปิดด้วย Python (`pandas`/`openpyxl`, ใช้ `python3 -I`) — ดูชื่อคอลัมน์ก่อน ห้ามสมมติรูปแบบ
- ภาพแคป: เปิดดูทุกภาพด้วย Read แล้วถอดตัวเลข (ไม่ต้อง commit ภาพ)
- จับคู่คลิปใน TikTok กับคลิปของทีม (ดู `office/posting-schedule.md` และ `office/weeks/*/`) จากวันโพสต์/หัวข้อ/ปก
- เขียน/ต่อท้าย `office/stats/<ปี>-W<สัปดาห์>.md`:

```
# สถิติ TikTok Studio — <ช่วงวันที่> (ที่มา: ไฟล์ export / ภาพแคป <วันที่ส่ง>)
## ภาพรวม
| ยอดวิว | ดูโปรไฟล์ | ไลก์ | คอมเมนต์ | แชร์ | ผู้ติดตามสุทธิ | ผู้ติดตามรวม |
## รายคลิป
| คลิป | วัน/เวลาโพสต์ | วิว | เวลาดูเฉลี่ย | % ดูจบ | ไลก์ | คอมเมนต์ | แชร์ | เซฟ | ผู้ติดตามใหม่ | For You % | ค้นหา % |
## กราฟการดูต่อ (ถ้ามี) — คนหลุดมากสุดที่วินาทีไหน ตรงกับฉาก/ซับอะไรในคลิป
## คำค้นหาที่พาคนมาดู (ถ้ามี)
## ผู้ติดตามออนไลน์ (ถ้ามี) — ชั่วโมง/วันที่สูงสุด
```

## 2. เรียกลูกทีม (ครั้งละตัว ทำทุกคลิปในครั้งเดียว)
1. `stats-tracker` — ส่ง path ไฟล์สถิติที่เพิ่งเขียน → อัปเดต `office/stats/tracker.md` + ความคืบหน้าเป้า 1,000 ผู้ติดตาม + สิ่งที่ควรทำทันที (ปักหมุด/ตอบคอมเมนต์)
2. `performance-analyst` — ให้เขียนรายงานลง `00-analysis.md` ในโฟลเดอร์สัปดาห์ถัดไป (`date -d "next monday" +%G-W%V`)
   สั่งเพิ่มให้ดูเป็นพิเศษ:
   - **% ดูจบ + กราฟการดูต่อ** เทียบกับฮุก 3 วิแรก และจุดที่คนหลุด (เปิดสคริปต์/ซับของคลิปนั้นดูว่าตรงประโยคไหน)
   - **ผู้ติดตามใหม่ต่อ 1,000 วิว** — หัวข้อไหนเปลี่ยนคนดูเป็นผู้ติดตามได้ดีที่สุด (สำคัญที่สุดสำหรับเป้า 1,000)
   - **เซฟ + แชร์ ต่อวิว** — คลิปไหนคนอยากเก็บ/ส่งต่อ
   - **แหล่งที่มา**: For You สูง = ฮุกดี · ค้นหาสูง = หัวข้อ/คำค้นดี (เอาคำค้นไปใส่แคปชัน)
   - เทียบรูปแบบ: มาสคอตเล่าเรื่อง vs ฟุตเทจจริง vs เกมทายอีโมจิ vs ทริค AI, ความยาว, วัน/เวลาโพสต์
3. ถ้ามีข้อมูลผู้ติดตามออนไลน์ → หัวหน้าทีมอัปเดตเวลาใน `office/posting-schedule.md` (เขียนเหตุผลสั้น ๆ + วันที่)

## 4. แจ้งเจ้าของช่อง (สั้น อ่านจบใน 1 นาที)
- 📊 ตัวเลขหลัก 3 ตัว: ผู้ติดตามรวม (เหลืออีกกี่คนถึง 1,000) · วิวรวม · ผู้ติดตามใหม่สัปดาห์นี้
- 🏆 คลิปที่ดีที่สุด + เพราะอะไร (1 บรรทัด) · 📉 คลิปที่แย่ที่สุด + เพราะอะไร
- ✅ 3 อย่างที่ควรทำสัปดาห์หน้า (เป็นงานที่ทำได้จริง)
- ⏰ เวลาโพสต์ที่เปลี่ยน (ถ้ามี)
- ข้อมูลที่ยังขาด และควรแคปอะไรเพิ่มรอบหน้า
- ลิงก์ไฟล์รายงาน `00-analysis.md`
