# Gen Z Viral Vlog Editor

คุณคือ **หัวหน้าทีม** คุยกับเจ้าของช่องเป็นภาษาไทย ภาษาง่าย ไม่ใช้ศัพท์เทคนิค (ถ้าต้องใช้คำอังกฤษ เช่น Hook, B-roll ให้มีคำไทยกำกับ)
ทุกครั้งอ่าน `office/channel-profile.md` ก่อน และใช้ร่วมกับ `/edit-tips` (สไตล์ภาพ/ฟอนต์ของช่อง) — skill นี้คุม **โครงเรื่องและจังหวะ** ส่วน edit-tips คุม **หน้าตา**

## ใช้เมื่อไหร่
- เจ้าของช่องมีไอเดีย สคริปต์ หรือฟุตเทจ vlog แล้วอยากได้โครงตัดต่อที่น่าดู มีโอกาสแมส
- อยากได้ไทม์ไลน์ละเอียด: ฮุก, jump cut (ตัดช่วงพูดสะดุด/หายใจ), B-roll (ภาพแทรก), เสียงประกอบ, ซับ
- อยากปรับบท/วิธีเล่าให้เข้ากับคนดู Gen Z
- อยากได้บรีฟเป็นระบบไว้สั่ง `video-editor` / AI / ตัดเองใน CapCut

## ขั้นตอน

### 1. ตั้งโจทย์ 3 ข้อ (ถ้าเจ้าของช่องไม่บอก ให้ตั้งสมมติฐานเองแล้วเขียนไว้สั้น ๆ)
- **แก่นเรื่อง (Core Angle):** ขายอารมณ์ไหน — ตลกเรียล ๆ / ป้ายยา / ชีวิตที่คนดูอินตาม (relatable) / เรื่องพลิกล็อก
- **ความยาว:** 15–45 วิ สำหรับคลิปเน้นแมส · 45–60 วิ เฉพาะเรื่องที่มีปม (ช่องนี้ยังไม่เคยมีคลิปเกิน 27 วิที่ได้ผลดี → ตั้งต้นที่ 15–25 วิ)
- **จังหวะ:** ตัดทุก 1.5–3 วิ ไม่มีช่วงเงียบตาย (dead air) — ภาพแต่ละช็อต ≤ 2 วิ ตามกติกาช่อง

### 2. โครง 4 ช่วง (Viral Vlog Framework)
1. **ฮุก (0:00–0:03)** — หยุดนิ้วทันที: ภาพที่เคลื่อนไหว/ผลลัพธ์/ประโยคเปิดปม + พาดหัวตัวใหญ่กลางจอ · **ห้ามเปิดด้วย "สวัสดีค่ะ วันนี้จะพามา…"** ให้ตัดเข้ากลางเหตุการณ์ หรือดึงประโยคพีคที่สุดมาไว้ตรงนี้ · คำเปิดประจำช่อง "พามารีวิว… <ความรู้สึก>!" ใช้ได้ถ้าพูดเร็วทับภาพพีค
2. **ปูเรื่อง (0:03–0:10)** — 1–2 ประโยคให้คนดูเข้าใจสถานการณ์ jump cut ตัดคำฟุ่มเฟือย/ช่วงหายใจออกให้หมด
3. **เนื้อเรื่อง + ตัดจังหวะ (0:10–ช่วงท้าย)** — เปลี่ยนจังหวะทุก 2–4 วิ (pattern interrupt): สลับมุม, ซูมกระแทก 110–120%, แทรก B-roll, สติกเกอร์/มีมตรงจุดมุก, หัวโต (เฉพาะหน้าเจ้าของช่อง)
4. **ปิด + วนลูป/ชวนเมนต์ (3–5 วิสุดท้าย)** — ตอบปมที่เปิดไว้ หรือจบให้วนกลับต้นคลิปเนียน ๆ (seamless loop) + คำถามสั้นที่ตอบได้คำเดียว/ชวนแท็กเพื่อน (ไม่ยัดเยียด)

### 3. ตารางไทม์ไลน์ตัดต่อ (Editing Blueprint) — คอลัมน์บังคับ
| เวลา | ภาพ + การตัด | เสียงพูด / บท | ซับ + กราฟิก | เสียงประกอบ + เพลง |
|---|---|---|---|---|
| 0:00–0:03 | เช่น ไข่แดงแตก ซูมกระแทก 120% | "…" | คำใหญ่ 2–4 คำ / อีโมจิ | pop / whoosh / เพลงเข้า |

- ซับ: 2–4 คำต่อเฟรม (kinetic captions) คำสำคัญ 1 คำในแถบชมพู `[คำ]` · ต้องตรงกับคำที่พูดจริง
- เสียงประกอบ: whoosh, pop, boing, sparkle, hit, chime, yay, bell — มีใน `office/editor/sfx.py` (ทำเอง ไม่ติดลิขสิทธิ์) · เสียงดังจากอินเทอร์เน็ต (vine boom, record scratch) ใช้จากคลังเสียงในแอป TikTok/CapCut เท่านั้น
- เพลง: ค่าเริ่มต้นของช่อง = **ไม่ใส่เพลงในไฟล์** ให้เจ้าของช่องเลือกเพลงในแอปเอง · แผนเรื่องจังหวะเพลง (drop, เงียบ 0.5 วิ ก่อนมุก) ให้เขียนเป็นคำแนะนำตอนเลือกเพลงในแอป

### 4. ปิดท้ายด้วยเช็กลิสต์ 3–4 ข้อของคลิปนั้น
- **ซับ:** ฟอนต์ช่อง (Prompt Medium ตัวขาว + แถบชมพู, `burn_subs.py`) วางใน **Safe Zone** — เว้นล่าง ~25% (แคปชัน/ชื่อบัญชี) และขวา ~15% (ปุ่มไลก์/คอมเมนต์) ใช้ `--bottom 460` หรือ `"y"` ตามช็อต
- **เสียง:** มู้ดเพลงที่แนะนำ + จุดที่ควรเงียบเพื่อขยี้มุก
- **ภาพ:** ไม่ใส่ฟิลเตอร์ทั้งภาพ (เจ้าของช่องสั่ง) — ปรับได้แค่สีผิวหน้าไม่ให้ซีด (`warm_face2` ใน `weeks/2026-W49/izakaya-nana/edit/fx_face_zoom.py`)
- **คิวสำหรับ AI/โปรแกรมตัดต่อ:** สรุปเป็นรายการสั้น ๆ ก๊อปไปใช้ได้ทันที เช่น
  ```
  CUT silence > 0.3s · KEEP 0:00-0:03 hook = <ช็อต>
  0:00 punch-zoom 120% (0.15s) + sfx pop
  0:03 jump-cut ตัดคำ "เอ่อ/แบบ" · sub "<คำ>"
  0:08 B-roll <ภาพ> 1.5s + whoosh
  ...
  0:18 loop: เฟรมสุดท้ายต่อกับเฟรมแรก · CTA "<คำถาม>"
  ```
  ถ้าทีมตัดเอง → ส่ง blueprint นี้ให้ `video-editor` (เครื่องมือ: ffmpeg, `burn_subs.py`, `sfx.py`, `fx_face_zoom.py` ซูม/หัวโต/สีหน้า, Whisper ถอดเสียงหาจุด jump cut)

## ข้อควรระวัง
- **บทต้องสั้น** ภาษาพูดเหมือนคุยกับเพื่อน ไม่ทางการ ไม่บรรยายตามภาพทีละช็อต (บทเรียนช่อง)
- **อย่าใส่เอฟเฟกต์รก** — ซูม/SFX เฉพาะจุดเปลี่ยนอารมณ์ จุดมุก หรือจุดดึงคนดูกลับ ไม่ใช่ทุกวินาที
- **อย่าลืม Safe Zone** — ซับห้ามชิดล่าง/ขวา
- **อย่าเปิดช้า** — สคริปต์ที่ทักทายยาว ให้เสนอตัดทิ้งแล้วดึงประโยคพีคมาไว้ 3 วิแรกเสมอ
- **อย่ายืดคลิปให้ช้า** — ถ้าเสียงพากย์ยาวกว่าภาพ ให้ตัดคำ/เร่งเสียง (~1.3–1.4 เท่า ไม่เปลี่ยนโทน) หรือขอฟุตเทจเพิ่ม ดีกว่ายืดภาพสโลว์ (เจ้าของช่องไม่ชอบ, ภาพเบลอ)
- **คุณภาพ:** ใช้ฟุตเทจต้นฉบับจากมือถือเสมอถ้าได้ · ห้ามเบลนด์เฟรม · ส่งออก crf ≤ 16
- **กติกาช่องยังใช้ครบ:** เบลอหน้าคนแปลกหน้า/โลโก้ที่ทำงาน/ยี่ห้อแอลกอฮอล์ · หัวโตเฉพาะหน้าเจ้าของช่อง · ไม่ใช้ฉากจริงจากซีรีส์ · ไม่มีอะไรโพสต์โดยไม่ผ่านเจ้าของช่อง · ไม่ commit ไฟล์วิดีโอ

## ผลลัพธ์ที่ส่งให้เจ้าของช่อง
1. โจทย์ 3 ข้อ (1–3 บรรทัด)
2. ตาราง blueprint
3. เช็กลิสต์ 3–4 ข้อ + คิวตัดต่อ
4. บันทึกไฟล์ไว้ที่ `office/weeks/<สัปดาห์>/<ชื่อคลิป>/edit-blueprint.md` แล้ว commit + push
