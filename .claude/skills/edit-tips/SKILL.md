คุณคือ **หัวหน้าทีม** คุยกับเจ้าของช่องเป็นภาษาไทย ภาษาง่าย ๆ

## วิธีใช้ skill นี้
- **ก่อนตัด/ทำปกทุกครั้ง** → เปิด `office/references/style/README.md` + ภาพในโฟลเดอร์นั้น เลือก 1 สไตล์ (A คาเฟ่ · B เที่ยว · C ไลฟ์สไตล์ · D สแครปบุ๊ก) ให้ตรงหัวข้อ แล้วบอก `video-editor` ว่าใช้สไตล์ไหน + ฟอนต์อะไร
- **เจ้าของช่องส่งภาพแนวที่ชอบมาเพิ่ม** → ย่อภาพ (กว้าง 720px) เก็บใน `office/references/style/` + เขียนสรุปในไฟล์ README นั้น (สไตล์ใหม่ หรือเติมสไตล์เดิม) → commit + push
- **เจ้าของช่องถาม/อยากตัดเอง** → สรุปเทคนิคที่เกี่ยวกับคลิปนั้นสั้น ๆ 3–5 ข้อ พร้อมขั้นตอนกดใน CapCut (มือถือหรือคอม) — ไม่ต้องเล่าทั้งคู่มือ
- **เจ้าของช่องแนบคลิปให้ทีมตัด** → ส่งต่อ `video-editor` พร้อมบอกให้ทำตาม "กติกาที่ทีมใช้" ด้านล่าง แล้วหัวหน้าทีมดูเฟรมเช็กว่าทำครบ (ช็อต ≤ 2 วิ, มีซูมกระแทกตรงจุดหักมุม ฯลฯ)
- **เจ้าของช่องส่งคลิปตัวอย่างของคนอื่นมาเพิ่ม** → ทำภาพรวมเฟรม (`ffmpeg ... tile`) + นับจุดตัด (`select='gt(scene,0.25)'`) ดูเทคนิค แล้ว **เพิ่มเทคนิคใหม่ลงไฟล์นี้** (ห้ามลอกเนื้อหา/มุก/ภาพของเขา) → commit + push
- แก้ไฟล์นี้ได้ตลอดเมื่อเจ้าของช่องบอกว่าชอบ/ไม่ชอบเทคนิคไหน (จดวันที่ไว้)

# คู่มือเทคนิคการตัดคลิป (สรุปจากคลิปตัวอย่างที่เจ้าของช่องส่งมา 22 พ.ย. 2026)

> ที่มา: คลิปของครีเอเตอร์อื่น 3 คลิป (สอนตัดต่อ/CapCut) — **เรียนรู้เทคนิคเท่านั้น ห้ามลอกเนื้อหา ภาพ มุก หรือ GIF/มีมจากหนังและการ์ตูน (ติดลิขสิทธิ์)**
> นักตัดต่อ (`video-editor`) อ่านไฟล์นี้ก่อนตัดทุกครั้ง
> ⚠️ ยังไม่เคยใช้กับคลิปที่โพสต์จริง — ยังไม่มีผลสถิติว่าเทคนิคช่วยจริงไหม

## A. คลิปไลฟ์สไตล์มีเสียงพากย์ (51 วิ · เปลี่ยนช็อต ~37 ครั้ง)
1. **เปิดคลิปด้วยตัดรัว** — 0–2 วิแรกเปลี่ยนภาพทุก ~0.2 วิ (8–10 ภาพ) แล้วขึ้นคำถามตัวใหญ่ ("ตัดคลิปยังไงน่า…") → หยุดนิ้วคนดู
2. **ช็อตละไม่เกิน 2 วิ** — หลังช่วงเปิด เปลี่ยนภาพทุก ~1.2–2 วิ ใช้ภาพประกอบ (B-roll) เยอะ ๆ ระหว่างพูด เช่น เดิน มือถือแก้ว คีย์บอร์ด ป้ายร้าน
3. **ข้อความบนจอทุกประโยค** + บางคำ **ตัวใหญ่เต็มจอ** เป็นจังหวะ (เช่น "กระชับ", "พูดเร็ว ๆ", "อย่าเกิน 2 วินาที") — คำเด้งทีละคำตามเสียงพูด
4. **พูดเร็ว** — ถ้าพูดช้าให้เร่งเสียงพากย์ (CapCut: แตะเสียง → Speed ~1.1–1.3 เท่า) คนดูไม่เบื่อ
5. **เสียงเอฟเฟกต์** ตรงจุดเปลี่ยนสำคัญ ช่วยให้คลิปสนุกขึ้น
6. ปิดด้วยภาพเจ้าของคลิป + ประโยคชวน ("ลองไปปรับใช้แล้วมาอวดกันได้")

## B. ทริค CapCut บนคอม (สำหรับเจ้าของช่องตอนตัดเอง)
1. **เอฟเฟกต์แว่นขยาย (Magnifying glass)** — ขยายจุดเล็ก ๆ ในภาพให้เห็นชัด (เช่น ข้อความบนป้าย) ปรับขนาด/ตำแหน่งได้
2. **Export แค่ช่วงที่ต้องการ** — เลือกช่วงบนไทม์ไลน์ → คลิกขวา / Range → Select by clip → Export
3. **ซ้อนวิดีโอเป็นตัวหนังสือโปร่ง** — ปรับ Opacity ~70–80% หรือ Blend ให้ตัวหนังสือบาง ๆ ไม่บังภาพ
4. **Compound clip** — เลือกหลายคลิป → คลิกขวา → Create compound clip รวมเป็นก้อนเดียว ย้าย/ใส่เอฟเฟกต์ทีเดียว (ดับเบิลคลิกเพื่อแก้ข้างใน)

## C. 3 เทคนิคหลัก (22 วิ)
1. **Jump cut** — ตัดช่วงเงียบ/ส่วนเกินทิ้ง จังหวะไวขึ้น คนดูเพลิน
2. **Motion zoom / crop (ซูมกระแทก)** — ซูมเข้าจุดสำคัญเร็ว ๆ ให้คนโฟกัส
3. **Transition** — เปลี่ยนฉากด้วยการ์ดคั่น/เอฟเฟกต์ ให้รู้ว่าเข้าเรื่องใหม่

## กติกาที่ทีมใช้ต่อจากนี้ (ปรับเข้ากับสไตล์ช่อง)
- ช็อตวิดีโอ/รูปนิ่ง **ไม่เกิน 2 วิ** ยกเว้นการ์ดข้อมูลที่ต้องให้อ่าน (≤ 5 วิ) — ถ้าภาพดีมีภาพเดียว ให้แตกเป็น 2–3 ช็อตด้วยการซูมคนละจุด
- **ซูมกระแทก** (ซูมเข้า 15–25% ใน 0.15 วิ) ตรงคำ/จุดหักมุม แทนซูมช้า ๆ ทั้งช็อต
- **แว่นขยาย** ใช้ตอนต้องให้คนอ่านข้อความเล็กในภาพ (ป้าย เมนู ราคา)
- **เปิดรัว** (0.15–0.25 วิ/ภาพ, ≤ 1.5 วิ) ใช้กับคลิปรีวิวที่มีช็อตเยอะ — ภาพสุดท้ายของช่วงรัวต้องเป็นช็อตฮุก
- คำสำคัญ 1 คำต่อคลิป ทำเป็น **ตัวใหญ่กลางจอ** ได้ (ไม่ใช่ทุกซับ)
- เสียงประกอบเฉพาะจุดสำคัญ (เจ้าของช่องไม่ชอบเสียงทุกครั้งที่เปลี่ยนช็อต)

## D. เทมเพลตคลิปถัดไป: "สติกเกอร์สแครปบุ๊กพาสเทล" (เจ้าของช่องเลือก 22 พ.ย. 2026)
> แรงบันดาลใจ: ช่องรีวิวบิวตี้ที่เจ้าของช่องชอบ (ภาพแคปหน้าคลิป/โปรไฟล์) — **ทำธีมของเราเอง ห้ามลอกภาพ สติกเกอร์ หรือข้อความของเขา**
> ตัวอย่างที่ทีมทำ: `python3 -I office/editor/scrapbook_mock.py <รูป> <out.jpg> [หัวข้อ1] [หัวข้อ2] [ป้ายไทย] [บับเบิล]` (ฉบับลองธีม ยังไม่ใช่เครื่องมือจริง)

**หน้าตา**
- **พื้นหลัง**: ลายทางแนวตั้งชมพู-ขาว (หรือเหลือง/ฟ้าพาสเทล) + ดาวเล็กชมพู/ฟ้ากระจาย
- **หัวข้ออังกฤษตัวเขียนเอียง ตัวใหญ่** สีเหลือง/ฟ้าพาสเทล ขอบขาวหนา + เงาชมพูเข้ม วางเอียงนิด ๆ
- **ป้ายภาษาไทยตัวหนากลม** (Kanit Bold) ตัวชมพูบนกล่องมิ้นต์ ขอบขาว วางเอียง 3–6°
- **สติกเกอร์**: บับเบิลคำพูด ("แบบนี้", "ว้าวทุกห้อง"), ดอกจัน/ดาวสีเหลือง-ฟ้า, โน้ตกล่องขาวมุมมน ("* ช่วงนี้ใช้บ่อยสุด ๆ")
- **ภาพจริง** วางเป็นรูปโพลารอยด์/สติกเกอร์ขอบขาว เอียงนิด มีเงา · ของที่รีวิวถือในมือ ถ่ายใกล้
- **หัวคน (ของเจ้าของช่องเท่านั้น) ไดคัตขอบขาว** แปะเป็นสติกเกอร์ได้ — ห้ามใช้หน้าคนอื่น/ดารา, ห้ามภาพ AI ของคนจริง
- **ซับ 2 ภาษา**: ไทยตัวหนาขาว ขอบเข้ม + คำสำคัญ 1 คำสีชมพู · อังกฤษตัวเล็กบรรทัดล่าง (คำสำคัญสีฟ้าได้)

**ในวิดีโอ**
- เฟรมแรก = หน้าปก (หัวข้อ + สติกเกอร์) ค้าง ≤ 1 วิ แล้วเข้าภาพจริง
- สติกเกอร์เด้งเข้า (scale 0→110→100% ใน 0.2 วิ) พร้อมเสียงป๊อป เฉพาะจุดสำคัญ
- คงกติกา ช็อต ≤ 2 วิ / ซูมกระแทก / แว่นขยาย จากส่วน A–C

**ที่ยังต้องทำก่อนใช้จริง** (ทำตอนมีคลิปถัดไป)
- ฟอนต์อังกฤษตัวเขียนแบบลายมือ (ตอนนี้ใช้ Playfair Italic แทน) — ต้องหาฟอนต์ฟรีที่ใช้เชิงพาณิชย์ได้ (เครื่องนี้โหลดจาก GitHub ไม่ได้ → ให้เจ้าของช่องเลือกฟอนต์ใน CapCut หรือส่งไฟล์ฟอนต์มา)
- ไดคัตหัวคน: ✅ ใช้ `office/editor/cutout.py --box ... --main --sticker` (ติดตั้ง 22 พ.ย.) — ใช้รูปที่เจ้าของช่องอยู่คนเดียวจะสะอาดสุด
- ทำเป็นสไตล์ซับใหม่ใน burn_subs.py (`--style scrapbook`) + เครื่องมือปก
