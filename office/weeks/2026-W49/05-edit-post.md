## ทางเลือกที่ 2: ตัดเองใน CapCut ฟรี (~15–20 นาที/คลิป)

**ตั้งค่าครั้งเดียว ใช้ทุกคลิป**
- โปรเจกต์ใหม่ อัตราส่วน **9:16** · 1080×1920 · 30fps
- **ฟอนต์**: ถ้า CapCut ไม่มีฟอนต์ช่อง (Fraunces / Dancing Script / Mali / Kanit / Prompt) → บอกทีมให้ทำ **การ์ด ป้าย หัวข้อ เป็นไฟล์ PNG พื้นใส** ส่งไปวางทับ (Overlay) แทน จะได้หน้าตาเหมือนกันทุกคลิป · ซับทั่วไปใช้ฟอนต์ไทยตัวหนาที่ใกล้ Prompt ที่สุดในแอป
- **ซูมกระแทก**: แตะช็อต → ใส่คีย์เฟรมที่จุดที่กำหนด (ขนาด 100%) → เลื่อนไป 0.15 วิ → ขยายเป็น 115–125% (คีย์เฟรมที่ 2)
- **สติกเกอร์เด้ง**: เพิ่มรูปจาก `office/assets/stickers/owner/` เป็น Overlay → แอนิเมชันเข้า "Pop/เด้ง" 0.2 วิ + เสียงประกอบ ค้นคำว่า "pop" วางตรงจุดเดียวกัน (**เฉพาะจุดที่ระบุ** ไม่ใส่ทุกช็อต)
- **ตัด**: แตะช็อต → เลื่อนเส้นไปเวลาที่กำหนด → "แยก" → ลบส่วนเกิน · ทุกช็อต ≤ 2 วิ (การ์ด ≤ 5 วิ) · ตัดฉับ ไม่ใส่ทรานซิชัน
- **ข้อความบนจอ** (ไม่มีเสียงพูด → ไม่ใช้ซับอัตโนมัติ พิมพ์เองตามสคริปต์): ≤ 2 บรรทัด วางช่วง **บน 1/3 ถึงกลางจอ** · ห้ามชิดขอบล่าง 1/5 และขอบขวา (ปุ่ม TikTok บัง) · ไม่ใส่อีโมจิ · คำใน `[ ]` 1 คำต่อซับ = คำเด่น
- **เพลง**: **ไม่ใส่ใน CapCut** → Export แล้วเพิ่มเพลงในแอป TikTok ตอนโพสต์ (คลังเพลงในแอป) · ห้ามเพลงประกอบซีรีส์/OST · ห้ามเสียงเพลงในห้าง
- Export 1080p 30fps

**สไตล์ข้อความ (เหมือนกันทุกคลิป ต่างแค่หัวข้อตามสไตล์คลิป)**
- ซับไทย: ตัวขาว ขอบเข้มบาง + เงาดำนุ่ม · **คำเด่นในแถบชมพู #FFD6E7 ตัวหนังสือ #7A0E3B** (คลิป 1 สไตล์ D: คำเด่นไทยตัวชมพู + บรรทัดอังกฤษตัวเล็กสีขาว คำเด่นสีฟ้า)
- ตำแหน่ง: กลางจอแนวนอน · สูงจากขอบบนประมาณ 30–40% ของจอ
