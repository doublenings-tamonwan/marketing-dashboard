## ส่วนที่ 1: แผนตัดต่อรายคลิป

### เลือกวิธีตัด (เลือก 1 ทาง ต่อคลิป)
- **ทาง A — ให้ทีมตัด (แนะนำ ประหยัดเวลาที่สุด):** ส่งในแชท = ไฟล์เสียงพากย์ + ภาพ/แคปทั้งหมดตามรายการด้านล่าง + **พิมพ์ประโยคที่พูดจริง** (ถ้าพูดต่างจากบท) → ทีมตัดและใส่ซับด้วย `office/editor/burn_subs.py --style clean` แล้วส่งไฟล์ตัวอย่างให้ตรวจ เจ้าของช่องแค่ดูแล้วตอบ ✅/แก้
- **ทาง B — ตัดเองใน CapCut ฟรี:** ทำตามขั้นตอนด้านล่าง (~30–40 นาทีต่อคลิป)

### สไตล์เดียวกันทั้ง 2 คลิป (สไตล์ช่อง)
| อย่าง | ค่าที่ใช้ |
|---|---|
| ขนาดงาน | 9:16 (1080×1920) · 30 fps |

**ซับอัตโนมัติใน CapCut (ทาง B):** ข้อความ → คำบรรยายอัตโนมัติ (ภาษาไทย) → **แก้ทีละซับให้ตรงกับข้อความในคอลัมน์ "ซับ:" ใน `02-scripts.md`** (ซับอัตโนมัติไทยมักผิดชื่อตัวละครและคำอังกฤษ) → เลือกซับอันแรก ตั้งสไตล์ตามตารางด้านบน → กด "ใช้กับทั้งหมด" → บันทึกเป็นสไตล์ที่ตั้งไว้ (ใช้ซ้ำคลิป 2 ได้เลย)

**เพลง:** เลือกจาก**คลังเพลงในแอป TikTok/CapCut** (เพลงที่ขึ้นว่าใช้เชิงพาณิชย์ได้) หรือให้ทีมแต่งด้วย `office/editor/make_music.py` · เสียงเพลงเบากว่าเสียงพากย์มาก (~15–20%) · **ห้ามใช้เพลงประกอบ/OST ของซีรีส์ และห้ามเพลงที่ไม่รู้สิทธิ์**

### คลิป 1: ทีมจักรพรรดิ vs ทีมเจ้าชาย (~19 วิ)

**ก่อนตัด:** เช็กชื่อตัวละครในซับไทย Disney+ (นาเวียร์ / โซวิเอชู / ไฮน์ริ / ราสตา) แล้ว — ถ้าสะกดต่าง ให้แก้ทั้งซับ ป้าย ปก แคปชัน และคอมเมนต์ปักหมุด

**ลำดับนำเข้าไฟล์**
1. `เสียงพากย์-คลิป1` (เทคที่ดีที่สุด) → วางแทร็กเสียงก่อน ใช้เป็นตัวกำหนดเวลา
2. AI-1 (ช็อต 1) → AI-2 → AI-3 → AI-4 → AI-5 → AI-1 อีกครั้ง (ช็อต 6)
   - ถ้าเลือก "ทางไม่ใช้ AI" ใน `04-shots.md`: ใช้ภาพมาสคอตจาก `character.py` แทนช็อต 1, 4, 6 (ให้ทีมเรนเดอร์ให้)
3. เพลงจากคลังในแอป (นำเข้าเป็นแทร็กสุดท้าย)

### คลิป 2: คาเฟ่เปิดใหม่ หายังไงให้เจอก่อนใคร? (~17.5 วิ)

**ก่อนตัด:** เบลอข้อมูลส่วนตัวในแคปทุกภาพ (ชื่อบัญชี รูปโปรไฟล์ คลิปคนอื่นในผลค้นหา ชื่อ+รูปคนเขียนรีวิวในแคป D) — ใน CapCut ใช้ "เอฟเฟกต์ → เบลอ" + มาสก์สี่เหลี่ยมทับจุดนั้น · จด**ชื่อปุ่มตามที่แอปเขียนจริง** ("วันที่โพสต์ / สัปดาห์นี้", "บันทึก/Save", "แชร์") แล้วใช้คำนั้นในซับ/ป้าย

**ลำดับนำเข้าไฟล์**
1. `เสียงพากย์-คลิป2` → วางแทร็กเสียงก่อน
2. รูป Moo Yoo ช็อตสวยสุด (ช็อต 1) → แคป B ย่อ (ซ้อนบนช็อต 1) → แคป A → แคป B → แคป C → แคป D → แคป E → แคป F → รูป Moo Yoo อีกมุม (ช็อต 8)
3. มาสคอตท่า point จาก `character.py` (ถ้าใช้ ให้ทีมเรนเดอร์) → วางทับช็อต 8 มุมล่าง
4. เพลงจากคลังในแอป
