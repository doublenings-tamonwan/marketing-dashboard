# เทคนิคการตัดต่อ (สรุปจากคลิปตัวอย่างที่เจ้าของช่องส่งมา 22 พ.ย. 2026)

> ที่มา: คลิปของครีเอเตอร์อื่น 3 คลิป (สอนตัดต่อ/CapCut) — **เรียนรู้เทคนิคเท่านั้น ห้ามลอกเนื้อหา ภาพ มุก หรือ GIF/มีมจากหนังและการ์ตูน (ติดลิขสิทธิ์)**
> นักตัดต่อ (`video-editor`) อ่านไฟล์นี้ก่อนตัดทุกครั้ง

## A. คลิปไลฟ์สไตล์มีเสียงพากย์ (51 วิ · เปลี่ยนช็อต ~37 ครั้ง)
1. **เปิดคลิปด้วยตัดรัว** — 0–2 วิแรกเปลี่ยนภาพทุก ~0.2 วิ (8–10 ภาพ) แล้วขึ้นคำถามตัวใหญ่ ("ตัดคลิปยังไงน่า…") → หยุดนิ้วคนดู
2. **ช็อตละไม่เกิน 2 วิ** — หลังช่วงเปิด เปลี่ยนภาพทุก ~1.2–2 วิ ใช้ภาพประกอบ (B-roll) เยอะ ๆ ระหว่างพูด เช่น เดิน มือถือแก้ว คีย์บอร์ด ป้ายร้าน
3. **ข้อความบนจอทุกประโยค** + บางคำ **ตัวใหญ่เต็มจอ** เป็นจังหวะ (เช่น "กระชับ", "พูดเร็ว ๆ", "อย่าเกิน 2 วินาที") — คำเด้งทีละคำตามเสียงพูด
4. **พูดเร็ว** — ถ้าพูดช้าให้เร่งเสียงพากย์ (CapCut: แตะเสียง → Speed ~1.1–1.3 เท่า) คนดูไม่เบื่อ
5. **เสียงเอฟเฟกต์** ตรงจุดเปลี่ยนสำคัญ ช่วยให้คลิปสนุกขึ้น
6. ปิดด้วยภาพเจ้าของคลิป + ประโยคชวน ("ลองไปปรับใช้แล้วมาอวดกันได้")

## B. ทริค CapCut บนคอม (สำหรับเจ้าของช่องตอนตัดเอง)
1. **เอฟเฟกต์แว่นขยาย (Magnifying glass)** — ขยายจุดเล็ก ๆ ในภาพให้เห็นชัด (เช่น ข้อความบนป้าย) ปรับขนาด/ตำแหน่งได้
2. **Export แค่ช่วงที่ต้องการ** — เลือกช่วงบนไทม์ไลน์ → คลิกขวา / Range → Select by clip → Export
3. **ซ้อนวิดีโอเป็นตัวหนังสือโปร่ง** — ปรับ Opacity ~70–80% หรือ Blend ให้ตัวหนังสือบาง ๆ ไม่บังภาพ
4. **Compound clip** — เลือกหลายคลิป → คลิกขวา → Create compound clip รวมเป็นก้อนเดียว ย้าย/ใส่เอฟเฟกต์ทีเดียว (ดับเบิลคลิกเพื่อแก้ข้างใน)

## C. 3 เทคนิคหลัก (22 วิ)
1. **Jump cut** — ตัดช่วงเงียบ/ส่วนเกินทิ้ง จังหวะไวขึ้น คนดูเพลิน
2. **Motion zoom / crop (ซูมกระแทก)** — ซูมเข้าจุดสำคัญเร็ว ๆ ให้คนโฟกัส
3. **Transition** — เปลี่ยนฉากด้วยการ์ดคั่น/เอฟเฟกต์ ให้รู้ว่าเข้าเรื่องใหม่

## กติกาที่ทีมใช้ต่อจากนี้ (ปรับเข้ากับสไตล์ช่อง)
- ช็อตวิดีโอ/รูปนิ่ง **ไม่เกิน 2 วิ** ยกเว้นการ์ดข้อมูลที่ต้องให้อ่าน (≤ 5 วิ) — ถ้าภาพดีมีภาพเดียว ให้แตกเป็น 2–3 ช็อตด้วยการซูมคนละจุด
- **ซูมกระแทก** (ซูมเข้า 15–25% ใน 0.15 วิ) ตรงคำ/จุดหักมุม แทนซูมช้า ๆ ทั้งช็อต
- **แว่นขยาย** ใช้ตอนต้องให้คนอ่านข้อความเล็กในภาพ (ป้าย เมนู ราคา)
- **เปิดรัว** (0.15–0.25 วิ/ภาพ, ≤ 1.5 วิ) ใช้กับคลิปรีวิวที่มีช็อตเยอะ — ภาพสุดท้ายของช่วงรัวต้องเป็นช็อตฮุก
- คำสำคัญ 1 คำต่อคลิป ทำเป็น **ตัวใหญ่กลางจอ** ได้ (ไม่ใช่ทุกซับ)
- เสียงประกอบเฉพาะจุดสำคัญ (เจ้าของช่องไม่ชอบเสียงทุกครั้งที่เปลี่ยนช็อต)
