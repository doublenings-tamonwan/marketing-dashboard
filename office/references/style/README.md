# คลัง reference สไตล์คลิปที่เจ้าของช่องชอบ

> **ทุกครั้งที่ตัดคลิป/ทำปก ให้เปิดไฟล์นี้และภาพในโฟลเดอร์นี้ก่อน แล้วเลือก 1 สไตล์ที่เข้ากับหัวข้อ**
> ภาพเป็นแคปหน้าจอช่องของครีเอเตอร์คนอื่น — ใช้ดูแนวทางเท่านั้น **ห้ามลอกภาพ โลโก้ สติกเกอร์ ข้อความ หรือมุกของเขา**
> เจ้าของช่องจะส่งแนวใหม่มาเพิ่มเรื่อย ๆ → เพิ่มภาพ (ย่อเหลือกว้าง 720px) + เขียนหัวข้อใหม่ในไฟล์นี้ + commit

## สิ่งที่ทุกสไตล์มีเหมือนกัน (ใช้ทุกคลิป)
1. **ปกมีหัวข้อใหญ่ช่วงกลางภาพ** (กริดโปรไฟล์ครอป 3:4 ตรงกลาง) — อ่านออกจากกริดได้ในพริบตา
2. **ฟอนต์ 2 แบบคู่กัน**: อังกฤษตัวเขียน/เซริฟหวาน ๆ ตัวใหญ่ + ไทยตัวหนาเล็กกว่า หรือป้ายเม็ดยาว (pill) บอกสถานที่/หมวด
3. **ตกแต่งน้อยแต่มีจุดเด่น**: ดอกจัน ✱ ดาว ✦ ลูกศรเขียนมือ วงเล็บเล็ก ๆ
4. **ภาพจริงสวยเป็นพระเอก** — แสงธรรมชาติ สีอุ่น คน/ของอยู่กลางภาพ ข้อความไม่บังจุดสำคัญ
5. ปกทุกคลิปของช่องหน้าตาไปทางเดียวกัน → กริดโปรไฟล์ดูเป็นระเบียบ

## สไตล์ A — รีวิวคาเฟ่/ร้านอาหาร (02, 03)
- ชื่อร้านอังกฤษ **เซริฟย้อนยุคหยัก ๆ สีเหลืองครีม** ตัวใหญ่กลางจอ + ไทยตัวเล็กบน/ล่าง + **ป้ายเม็ดยาวขาว/ดำ บอกย่าน** ("ลำลูกกา", "ปิ่นเกล้า", "ใกล้ MRT …")
- ดอกจัน ✱ สีชมพู/ฟ้า ข้างชื่อร้าน · เปิดด้วยช็อตทางเข้า/บรรยากาศกว้าง
- **ใช้กับ**: พามารีวิว (คาเฟ่/ที่เที่ยว) — ตรงกับหัวข้อของช่อง
- ฟอนต์: **Fraunces Bold** (ชื่อร้าน/ชื่อเมนูอังกฤษ) + **Chonburi** (ข้อความไทย) ← เจ้าของช่องเลือก 24 พ.ย. · ป้ายเม็ดยาวเล็กใช้ Kanit ได้

## สไตล์ B — เที่ยวต่างประเทศ (04)
- ภาพวิวเต็มจอ คนตัวเล็กอยู่ในภาพ · หัวข้อ **เซริฟอังกฤษสีขาว** ("Kyoto in Autumn", "Winter Trip") + ไทยตัวหนา + ป้ายแดง "EP.1/EP.2", ดาว 5 ดวง, ป้ายเล็ก "Hidden spot"
- **ใช้กับ**: คลิปเที่ยวต่างประเทศ (ญี่ปุ่น/เกาหลี ที่เจ้าของช่องมีฟุตเทจ)
- ฟอนต์: **Fraunces / Playfair Italic** + **Kanit Bold**

## สไตล์ C — ไลฟ์สไตล์/วล็อกชีวิตประจำวัน (05, 06)
- หน้าคน/มือถือของเป็นหลัก · ข้อความ **อังกฤษตัวเล็กมินิมอล สีขาว** ("day in my life", "spend a morning with me") + เวลาเล็ก ๆ ("7:00 am – 20:00 pm") + ดาว ✦ เล็ก
- ไม่มีกรอบ/สติกเกอร์เยอะ — เรียบ สะอาด
- **ใช้กับ**: ชีวิตพนักงานประจำ / Life after 5 pm / ของใช้
- ฟอนต์: **Dancing Script** (คำเด่น) หรือ **Prompt Medium** ตัวเล็ก

## สไตล์ D — สติกเกอร์สแครปบุ๊กพาสเทล (01, 07, 08, 09)
- พื้นลายทาง/ลายตาราง พาสเทล + ดาว · หัวข้ออังกฤษตัวเขียนเหลือง-ฟ้า ขอบขาวหนา · ไทยตัวหนาในกล่องเอียง · บับเบิลคำพูด · โน้ตกล่องขาว · หัวคนไดคัต · ซับ 2 ภาษา (ไทยขาวขอบเข้ม คำเด่นสีชมพู + อังกฤษตัวเล็ก คำเด่นสีฟ้า)
- **ใช้กับ**: how-to/ทริค, รีวิวของชิ้นเล็ก, คลิปความรู้แบบสนุก
- ฟอนต์: **Dancing Script Bold** (หัวข้อ) + **Kanit Bold** (ป้าย) + **Mali Bold** (บับเบิล/โน้ต/ซับน่ารัก)
- รายละเอียด: `/edit-tips` ส่วน D · ภาพลองธีม `office/editor/scrapbook_mock.py`
